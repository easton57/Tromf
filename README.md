# Vibe Game

A Phaser.js game project.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open your browser and navigate to `http://localhost:8080`

## Project Structure

- `index.html` - Main HTML file
- `src/main.js` - Main game logic
- `styles/main.css` - Game styling
- `package.json` - Project dependencies and scripts

## Development

The game uses Phaser 3.80.1 and includes:
- Basic scene setup with preload, create, and update functions
- Arcade physics system
- Responsive design
- Development server with live reload

## Next Steps

- Add sprites and assets to the `assets/` folder
- Implement game mechanics in the scene functions
- Add more scenes as needed
- Customize the game configuration in `src/main.js`
